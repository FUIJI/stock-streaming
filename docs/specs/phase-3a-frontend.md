# Phase 3a — Dashboard UI รอบแรก

> สถานะ: **Approved — กำลังทำ** · Branch: `feat/frontend-dashboard` · ใช้ API จาก Phase 2.5

## เป้าหมาย
หน้าเดียวที่บอกได้ทันทีว่า "ตอนนี้ตลาดอยู่ช่วงไหน หุ้นแต่ละตัวขึ้นหรือลงเท่าไหร่ และกราฟเป็นข้อมูลสดหรือย้อนหลัง"

## Decisions
| # | เรื่อง | ตัดสินใจ |
|---|---|---|
| U1 | ภาษาของ UI | อังกฤษ (โปรเจคพอร์ต) · เวลาแสดงเป็นเวลาไทย (ICT, UTC+7) ทั้งหมด |
| U2 | ช่วง pre/post-market บนกราฟ | ใช้สีแท่งที่จางลง (lightweight-charts ไม่มีแถบแรเงาพื้นหลังแบบในตัว) ตัดช่วงตามเวลา ET |
| U3 | การอัปเดตข้อมูล | `/quotes` ทุก 15 วินาที · `/market/status` ทุก 60 วินาที · กราฟใช้ WebSocket เหมือนเดิม |
| U4 | Test | ไม่เพิ่ม framework · ฟังก์ชันคำนวณ (เวลา, session, รวม trade เข้าแท่ง) แยกไว้ใน `src/lib/` และทดสอบด้วย `node --test` ที่มากับ Node 22 |
| U5 | การทดสอบหน้าจอ | รัน API จริง + simulator + Alpaca จำลองในเครื่อง แล้วถ่ายภาพหน้าจอด้วย Playwright (ต้องเพิ่ม `ALPACA_DATA_URL` ให้ API ชี้ไป server จำลองได้) |

## Tickets
- **F1 — API client + utils:** type และ fetcher ของ `/quotes`, `/market/status`, `/symbols/details`, `/candles?interval=` · ฟังก์ชันเวลาไทย, session ตามเวลา ET, รวม trade เข้าแท่งตาม interval
- **F2 — ป้ายสถานะตลาด:** Pre-market / Market open / After-hours / Closed พร้อมเวลา (ไทย) ที่จะเปลี่ยนสถานะ และเวลานับถอยหลัง · ถ้า API ไม่พร้อมแสดง "status unavailable"
- **F3 — การ์ดหุ้น (แทนปุ่มเลือกหุ้นเดิม):** symbol, ชื่อบริษัท, ราคา, change และ % (สีเขียว/แดง) · คลิกแล้วเลือกกราฟ
- **F4 — กราฟ:**
  - ปุ่ม interval 1m / 5m / 1h / 1d
  - แกนเวลาเป็นเวลาไทย
  - แท่งช่วง pre/post สีจาง
  - กราฟ volume ด้านล่าง
  - แท่งล่าสุดขยับสดตาม interval ที่เลือก
  - จุดสถานะ Live แสดงสถานะ WebSocket จริง
- **F5 — ข้อความและความเรียบร้อย:** ข้อความเมื่อไม่มีข้อมูล หรือเมื่อ API มีปัญหา (ไม่อ้างถึง "พอร์ต 8000" อีก) · หัวเว็บตรงกับ stack ที่รันจริง · ใช้งานบนมือถือได้
